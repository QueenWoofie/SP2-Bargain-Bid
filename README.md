## About the Project
Bargain Bid is a front-end application where users can register, log in, and participate in auctions.  
Unregistered users can browse and search listings, while registered users can create, edit, delete listings, place bids, and manage their profile.  

## Features
- User authentication (register & login with `@stud.noroff.no`)
- Profile management (bio, avatar, banner, credits)
- Browse, search, and filter listings
- Create, edit, and delete listings
- Place and view bids in real-time
- Credits visible on every page when logged in
- Responsive design with Tailwind CSS

## Tech Stack
- **HTML**
- **Tailwind CSS**
- **JavaScript**
- **Noroff Auction API**
- Hosting: Netlify
- Design: Figma
- Planning: GitHub Projects
